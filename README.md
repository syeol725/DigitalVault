# DigitalVault Portable

Windows 10/11 64비트용 USB 휴대형 암호화 문서 금고입니다.

## 주요 기능

- AES-256-GCM 인증 암호화
- 비밀번호 기반 키 파생: scrypt
- 문서 추가, 목록, 열기, 내보내기, 삭제, 검색, 이름 변경
- 비밀번호 변경 및 복구 키를 통한 비밀번호 재설정
- 로그인 5회 실패 시 60초 로그인 제한
- 복구 키 발급 및 복구 키를 이용한 비밀번호 재설정
- 암호화된 금고 백업 및 새 폴더로 복원
- 문서·인덱스 무결성 검사
- 암호화된 보안 이벤트 기록
- 문서별 암호화 용량 표시
- 실행 파일이 있는 폴더에 기본 금고 데이터 저장
- 작업 완료 후 계속 사용 여부 확인
- Windows용 단일 실행 파일 빌드

## 지원 파일 형식

PDF, DOCX, TXT, PPTX, XLSX, JPG, JPEG, PNG

## USB에서 사용하기

1. GitHub Actions에서 `DigitalVault-Windows-x64` 아티팩트를 다운로드합니다.
2. ZIP 파일을 압축 해제합니다.
3. 압축 해제한 `DigitalVault.exe`를 USB에 복사합니다.
4. USB에서 `DigitalVault.exe`를 실행합니다.
5. 금고 저장 폴더 입력에서 Enter를 누릅니다.
6. USB 안에 생성되는 `DigitalVaultData` 폴더에 금고 데이터가 저장됩니다.

다른 Windows 컴퓨터에서도 실행 파일과 `DigitalVaultData` 폴더를 함께 사용해야 합니다.

## Windows에서 직접 빌드하기

1. Windows 10/11 64비트와 Python을 준비합니다.
2. 저장소 폴더에서 `build_windows.bat`를 실행합니다.
3. 빌드가 성공하면 `dist\DigitalVault.exe`가 생성됩니다.

## GitHub Actions 빌드

1. 저장소의 **Actions** 탭을 엽니다.
2. **Build Windows DigitalVault** 워크플로를 선택합니다.
3. **Run workflow**를 실행합니다.
4. 실행이 완료되면 아티팩트 `DigitalVault-Windows-x64`를 다운로드합니다.

태그를 `v1.0.0` 형식으로 푸시해도 빌드가 실행됩니다.

## 보안상 주의사항

- 복구 키를 별도로 보관한 경우 복구 키로 새 비밀번호를 설정할 수 있습니다. 비밀번호와 복구 키를 모두 잃으면 금고 데이터에 접근할 수 없습니다.
- `DigitalVaultData` 폴더 전체를 별도 저장장치에 백업하세요.
- 내보낸 문서는 금고 외부의 일반 파일이며 자동으로 암호화되지 않습니다.
- 문서를 열 때 임시 복호화 파일이 생성됩니다. 프로그램은 사용자가 Enter를 누른 뒤 임시 폴더 삭제를 시도하지만, 문서 앱·운영체제·백업·스왑 등이 복사본을 남길 수 있어 완전한 흔적 제거를 보장하지 않습니다.
- 로그인 제한 파일은 USB 안에 저장됩니다. 파일을 직접 수정할 수 있는 공격자를 막는 보안 경계로 간주하면 안 됩니다.
- USB를 쓰기 작업 중 분리하지 마세요.
- 이 프로그램은 백신, 백업, USB 분실 방지 기능을 대체하지 않습니다.

## 데이터 형식 안내

이 버전은 현재 제공된 새 코드의 암호화 형식을 사용합니다. 이전 버전에서 만든 금고 데이터와 호환되지 않을 수 있으므로, 기존 금고 데이터를 새 버전에서 열 수 있다고 가정하지 마세요.


## 강화된 보안 기능

- scrypt 강화 설정: N=2^17, r=8, p=1 (약 128 MiB 메모리 사용)
- 암호화 포맷 버전과 KDF 설정값을 vault.json에 기록
- AES-256-GCM의 AAD로 마스터 키 래핑, 인덱스, 문서 데이터를 구분해 인증
- 마스터 키 재발급 시 현재 비밀번호를 재확인하고 문서·인덱스·키 메타데이터를 함께 갱신
- 임시 복호화 폴더와 파일의 접근 권한 제한
- 오래된 금고 전용 임시 폴더 정리
- 콘솔 입력 대기 중 5분 비활동 시 자동 잠금

## 보안 테스트

GitHub Actions의 Security tests 워크플로가 코드 변경 시 Python 문법 검사와 다음 회귀 테스트를 실행합니다.

- AES-GCM 암호문 변조 및 AAD 불일치 감지
- 허용되지 않은 KDF 설정 거부
- 비밀번호 변경 후 재로그인
- 마스터 키 재발급 후 문서 복호화

## 추가 보안 주의사항

- scrypt 설정은 약 128 MiB의 메모리를 사용하므로 메모리가 적은 컴퓨터에서는 키 파생이 느리거나 실패할 수 있습니다.
- 자동 잠금은 콘솔 입력 대기 상태를 기준으로 합니다. 운영체제 파일 선택 창이 열린 동안까지 전역 유휴 시간을 감시하지는 않습니다.
- 임시 파일 삭제는 완전한 흔적 제거를 보장하지 않습니다. 문서 앱, 운영체제, 백업 및 스왑 영역에 복사본이 남을 수 있습니다.
- 마스터 키 재발급 중에는 USB를 분리하거나 금고 폴더를 이동하지 마세요.


## 복구 키

- 새 금고를 만들면 256비트 수준의 무작위 복구 키가 생성되어 최초 실행 화면에 한 번 표시됩니다.
- 복구 키는 별도 저장장치나 안전한 암호 관리자에 보관하고, 금고 폴더와 같은 USB에만 보관하지 마세요.
- 비밀번호 입력 화면에서 R을 입력한 뒤 복구 키와 새 비밀번호를 입력하면 마스터 키를 복원하고 비밀번호를 재설정합니다.
- 기존 금고에 복구 키가 없다면 로그인 후 메뉴의 "복구 키 발급"을 사용하세요.
- 마스터 키 재발급 시 기존 복구 키를 확인하여 새 마스터 키에 다시 연결합니다.
- 복구 키를 잃어버린 경우, 현재 비밀번호로 로그인한 뒤 새 복구 키를 발급하세요.

## 백업 및 복원

- 메뉴에서 금고 백업을 선택하면 암호화된 메타데이터·인덱스·문서 파일을 ZIP으로 묶고 각 파일의 SHA-256 해시를 매니페스트에 기록합니다.
- 백업은 이미 암호화된 금고 파일을 그대로 보관합니다. ZIP 자체에 별도의 비밀번호 암호화를 추가하는 것은 아닙니다.
- 복원은 존재하지 않는 새 폴더에만 수행하며 기존 폴더를 덮어쓰지 않습니다.
- 복원 후 해당 폴더를 금고 위치로 지정해 로그인하고 무결성 검사를 실행하세요.
- 백업 파일도 복구 키와 마찬가지로 안전한 별도 장소에 보관하세요.

## 추가 관리 기능

- 문서명 검색 및 문서명 변경
- 파일명 기준 정렬, 형식 및 암호화 데이터 크기 표시
- 무결성 검사에서 인덱스와 각 문서의 AES-GCM 인증 태그 확인
- 보안 이벤트를 마스터 키로 암호화하여 기록
- 금고 정보에서 문서 수, 암호화 데이터 용량, 복구 키 설정 여부 표시

보안 이벤트 기록은 USB 내부에 저장되므로, 저장장치에 직접 접근할 수 있는 공격자에 대한 완전한 위변조 방지 수단은 아닙니다.
