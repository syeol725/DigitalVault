DigitalVault Portable - USB 사용 안내

[지원 운영체제]
Windows 10 / 11 64비트 전용
macOS 및 Linux 미지원

1. 설치 및 실행
① GitHub Actions에서 DigitalVault-Windows-x64 다운로드
② ZIP 파일 압축 해제
③ USB에 압축 해제된 파일 복사
④ DigitalVault.exe 실행

2. 최초 실행
① 금고 저장 폴더 지정
② 새 금고 생성
③ 비밀번호 설정
④ 설정한 비밀번호로 로그인

기본 저장 위치:
USB 드라이브:\DigitalVaultData

3. 문서 관리
- 문서 추가
- 문서 목록
- 문서 열기
- 문서 내보내기
- 문서 삭제
- 비밀번호 변경
- 금고 잠금 및 종료

4. 문서 내보내기
암호화된 문서를 복호화하여 지정한 위치에 저장합니다.
내보낸 파일은 일반 파일이므로 금고 외부에서는 암호화되지 않습니다.

5. 금고 백업
DigitalVaultData 폴더를 별도 저장장치에 백업하는 것을 권장합니다.

6. 프로그램 업데이트
① 새 버전의 DigitalVault.exe 다운로드
② 기존 실행 파일 교체
③ 기존 DigitalVaultData 폴더 유지

7. 주의사항
- 비밀번호를 안전하게 보관하세요.
- USB 분리 전 프로그램을 정상 종료하세요.
- 금고 데이터 폴더를 삭제하지 마세요.
