DigitalVault Portable - USB 사용 안내

[지원 운영체제]
Windows 10 / 11 64비트 전용

1. 실행 파일 준비
① GitHub 저장소의 Actions 탭으로 이동
② Build Windows DigitalVault 실행 결과 선택
③ DigitalVault-Windows-x64 아티팩트 다운로드
④ ZIP 압축 해제
⑤ DigitalVault.exe를 USB에 복사

2. 최초 실행
① USB에서 DigitalVault.exe 실행
② GUI 로그인 창에서 기본 금고 위치 확인
③ 새 금고라면 8자 이상 비밀번호 입력 및 확인
④ 복구 키가 표시되면 안전한 별도 장소에 보관

기본 저장 위치:
USB 드라이브:\DigitalVaultData

3. GUI 사용
로그인하면 문서 보관함 화면이 열립니다.
왼쪽 메뉴에서 문서 추가, 내보내기, 보안 관리,
백업 및 복구, 무결성 검사, 금고 정보를 선택합니다.
문서 목록에서 항목을 선택하고 열기·이름 변경·삭제를 수행할 수 있습니다.
문서를 더블 클릭해도 열 수 있습니다.
복구 키로 비밀번호를 바꾸려면 로그인 화면에서
'복구 키로 비밀번호 재설정'을 선택합니다.
자동 유휴 잠금은 적용되지 않으므로 사용 후 '잠금 및 종료'를 누르세요.
로그인 비밀번호를 5회 틀리면 60초 동안 로그인이 제한됩니다.

4. 문서 내보내기
내보낸 문서는 금고 외부에 일반 파일로 저장되며 암호화 상태가 아닙니다.

5. 복구 키
최초 금고 생성 시 표시되는 복구 키를 별도 장소에 보관하세요.
비밀번호를 잊으면 로그인 화면에서 '복구 키로 비밀번호 재설정'을 선택해 새 비밀번호를 설정할 수 있습니다.
복구 키와 비밀번호를 모두 잃으면 금고를 복구할 수 없습니다.

문서 목록은 파일명 기준으로 정렬되며, 번호·파일명·형식·암호화 크기가 표 형태로 표시됩니다.

6. 백업 및 불러오기
GUI의 백업 및 복구 메뉴에서 암호화된 금고 백업 ZIP을 만들거나, 현재 열려 있는 금고에 백업 문서를 병합할 수 있습니다.
기존 문서는 유지되며, 이름이 중복되는 문서는 별도 이름으로 추가됩니다.
백업 ZIP 자체에 별도 비밀번호가 설정되는 것은 아닙니다.

7. 프로그램 업데이트
① 새 DigitalVault.exe를 다운로드
② USB의 기존 실행 파일 교체
③ DigitalVaultData 폴더는 유지

8. 주의사항
- 비밀번호와 복구 키를 모두 잃으면 복구할 수 없습니다.
- USB 분리 전 프로그램을 정상 종료하세요.
- 금고 데이터 폴더를 삭제하거나 이름을 바꾸지 마세요.
- 문서를 열면 임시 복호화 파일이 생성되며, 프로그램이 삭제를 시도합니다. 완전한 흔적 제거는 보장되지 않습니다.
- 이전 버전의 금고 데이터와 호환되지 않을 수 있습니다.
